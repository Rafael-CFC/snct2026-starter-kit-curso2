# Painel Verde Garopaba — SNCT 2026 · IFSC Garopaba

1. Abra o arquivo `index.html` com duplo-clique (funciona sem internet).
2. **BLOCO 1** (`index.html`): personalize o titulo e o subtitulo do painel.
3. **BLOCO 2** (`js/app.js`): cadastre novos ecopontos no array `LOCAIS_COLETA`, usando uma das categorias dos botoes (Reciclaveis, Vidro, Eletronicos, Oleo).
4. Clique nos botoes de filtro e veja a funcao `filtrarEcopontos()` mostrar so os locais daquela categoria.
5. Salve (Ctrl+S), atualize o navegador (F5) e publique no GitHub Pages.
